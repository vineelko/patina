# General Rust Learning Resources

This page is a curated collection of learning resources the Patina project has found helpful for learning Rust. It is
not meant to be an exhaustive list of all Rust learning resources, but to help guide newcomers to UEFI Rust development
to a set of resources that we've found particularly useful.

## Recommended First Stops

- [Official Rust Language Book](https://doc.rust-lang.org/book/) - Main language book, recommended place to start.
- [Official Rust Language Site](https://rust-lang.org/learn/) - Contains books, tools, and other learning resources.
- [Rust by Example](https://doc.rust-lang.org/rust-by-example/) - Official documentation with Rust examples for various
  concepts.
- [Comprehensive Rust](https://google.github.io/comprehensive-rust/) - Free course developed by Google's Android team,
  from Rust fundamentals to advanced topics. Its
  [bare-metal course](https://google.github.io/comprehensive-rust/bare-metal.html) covers `no_std`, microcontrollers,
  and bootloader and kernel development.
- [Writing an OS in Rust](https://os.phil-opp.com/) - A blog series that guides you through writing an operating system
  in Rust from scratch. An excellent resource for learning low-level programming with Rust.

## Additional Learning Resources

Use these to deepen your understanding of Rust and explore more advanced topics.

- [Ferrous Systems Rust Training](https://github.com/ferrous-systems/rust-training) - Created for people with anywhere
  from zero Rust experience (but with a programming background) to advanced Rust knowledge.
- [Learn Rust the Dangerous Way](https://cliffle.com/p/dangerust/) - A guide to learning Rust with a focus on unsafe
  code and low-level programming.
- [Rustonomicon](https://doc.rust-lang.org/nomicon/) - A guide to writing unsafe Rust code correctly and understanding
  the intricacies of Rust's safety guarantees.
- [Rust Atomics and Locks](https://mara.nl/atomics/) - Free online book covering memory ordering, synchronization, and
  processor behavior on Intel and ARM.
- [The Embedded Rust Book](https://docs.rust-embedded.org/book/) - Rust Embedded Working Group resource covering
  bare-metal development, peripherals, interrupts, and C interoperability.

## Interesting Reference Projects

- [Redox](https://www.redox-os.org/) - A complete Unix-like microkernel-based operating system written in Rust, with a
  focus on security, reliability and safety.

## Additional References

- [The Rust Reference](https://doc.rust-lang.org/reference/) - The primary language reference, including type
  representation, ABI, inline assembly, and similar topics. More of a reference rather than a tutorial.
- [Rust Core Library Documentation](https://doc.rust-lang.org/core/) - Official API documentation for the library
  underlying `no_std` Rust, including pointers, memory operations, atomics, and their safety requirements.
- [Official Rust Language Forum](https://users.rust-lang.org/) - A place to ask questions and discuss Rust with the
  community.
- [Rustup Components History](https://rust-lang.github.io/rustup-components-history/) - A reference for the history of
  Rustup components and their versions.
